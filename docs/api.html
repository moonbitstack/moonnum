pub fn parse_int(StringView, base? : Int32) -> @bigint.BigInt raise Refused

int(text, base): an integer in any base from 2 to 36, with Python's spelling rules.

Surrounding whitespace is allowed, the sign is optional, digits may be separated by single underscores, and base = 0 means "read the prefix": 0x for hexadecimal, 0o for octal, 0b for binary, decimal otherwise — and, as in Python, leading zeros are then not allowed.

pow(base, exp, modulus), and pow(base, exp) when modulus is absent.

With a modulus and a negative exponent the result is the modular inverse raised to -exp, which is Python's behaviour since 3.8. Without a modulus a negative exponent has no integer answer and is refused.

pub fn to_bytes(@bigint.BigInt, length~ : Int32, big? : Bool, signed? : Bool) -> Bytes raise Refused

int.to_bytes: length bytes holding n, big-endian unless big~ = false.

A signed result is two's complement; an unsigned one refuses negatives.

Complex numbers

Complex, its arithmetic, and its repr.

pub fn parse_complex(StringView) -> Complex raise Refused

complex(text): 1+2j, (1+2j), j, -j, 1e3j, and 3+5i.

The i suffix is this library's addition; Python only reads j.

pub fn repr_complex(Complex) -> String

repr(z): (1+2j), 2j, (-0-1j), (nan+infj).

pub(all) struct Complex { re : Double

A complex number: z.re + z.im * j.

Adds, subtracts, multiplies, negates and compares with ==; division is Complex::divide because it can refuse a zero divisor.

Implements Add (+) · Default (default()) · Eq (== and !=) · Mul (*) · Neg (unary -) · Show (to_string()) · Sub (-) — the methods they promote are public on Complex.

pub fn Complex::abs(Self) -> Double

abs(z): the Euclidean norm, infinity when either part is infinite.

pub fn Complex::conjugate(Self) -> Self

z.conjugate().

pub fn Complex::divide(Self, Self) -> Self raise Refused

self / other.

A function rather than an operator, for the same reason as Fraction::divide: division by zero has to be reported, and Div cannot.

pub fn Complex::format(Self, StringView) -> String raise Refused

Format a complex number: the real part with the specifier's sign, the imaginary part forced positive, then j, in parentheses unless the real part is a positive zero.

pub fn Complex::j() -> Self

The imaginary unit.

pub fn Complex::new(Double, Double) -> Self

Complex(re, im).

pub fn Complex::pow(Self, Self) -> Self raise Refused

z ** w, including Python's special cases.

An exponent that is a small integer is applied by repeated squaring, as CPython does; anything else goes through the polar form, which is why (1+1j) ** 2 is exactly 2j and (1+1j) ** 2.0 is not.

Fractions

Exact rationals, kept in lowest terms.

pub fn parse_fraction(StringView) -> Fraction raise Refused

Fraction(text): "3/4", "-1.25", "1e-3", "7".

Whitespace is allowed around the sign, the slash and the ends; digits may be separated by single underscores. The decimal and exponent forms are read as exact powers of ten, never through a float.

pub fn repr_fraction(Fraction) -> String

repr(Fraction(3, 4)).

pub(all) struct Fraction { num : @bigint.BigInt

A rational number. den is always positive and gcd(num, den) is always 1, so num and den can be read directly.

Adds, subtracts, multiplies, negates, compares with == and an ordering; division is Fraction::divide because it can refuse a zero divisor.

Implements Add (+) · Compare (<, <=, >, >=) · Default (default()) · Eq (== and !=) · Mul (*) · Neg (unary -) · Show (to_string()) · Sub (-) — the methods they promote are public on Fraction.

Division is a function and not an operator here: MoonBit's Div trait cannot raise, and a fraction that silently divides by zero or panics would be worse than one that says ZeroDivision.

The exact value of a float, as a fraction. 0.1 is not 1/10 here; it is 3602879701896397/36028797018963968, which is what the double holds.

pub fn Fraction::of_int(@bigint.BigInt) -> Self

The exponent is applied to the numerator and the denominator separately, so (2/3) ** 100 is one exact ratio and not a double that nearly is. A negative exponent reciprocates, which is why 0 ** -1 is ZeroDivision and 0 ** 0 is 1, as in Python.

Numbers

The tower: one value that can be any of the four kinds.

pub fn parse(StringView) -> Number raise Refused

parse(text): read a Python number literal and keep the kind it spelled.

A / makes a fraction, a trailing j or i makes a complex number, a point or an exponent or inf/nan makes a float, and anything else is an integer in whatever base its prefix names.

pub(all) enum Number { Int(@bigint.BigInt)

A number of any kind, as the tower arranges them.

Promotion goes Int → Fraction → Float → Complex. Comparison is exact across the tower: an integer is never rounded to a float to be compared with one.

Implements Add (+) · Eq (== and !=) · Mul (*) · Neg (unary -) · Show (to_string()) · Sub (-) — the methods they promote are public on Number.

pub fn Number::compare_numeric(Self, Self) -> Int32 raise Refused

Compare two real numbers, exactly.

Raises Domain for a NaN operand and for a complex number with a non-zero imaginary part, which Python refuses to order.

pub fn Number::divide(Self, Self) -> Self raise Refused

a / b, with Python's result kinds: two integers divide to a float, a fraction stays exact, and a complex number is complex.

pub fn Number::equal_numeric(Self, Self) -> Bool

a == b, across the tower: 1 == 1.0 == Fraction(1) == 1 + 0j.

pub fn Number::floor_mod(Self, Self) -> Self raise Refused

a % b: the remainder that takes the sign of the divisor.

pub fn Number::floordiv(Self, Self) -> Self raise Refused

a // b.

pub fn Number::pow(Self, Self) -> Self raise Refused

a ** b.

pub fn Number::to_double(Self) -> Double raise Refused

The value as a double, or Overflow when it is infinite or not real.

Errors

One type, four cases.

pub(all) suberror Refused { Malformed(at~ : Int32, reason~ : String)

Everything this library refuses, in one type.

Malformed carries the offset where the input stopped making sense, in UTF-16 code units — the unit StringView indexes by — so a caller can point at the character instead of at the string.

Implements Show (to_string()) — the method it promotes is public on Refused.
