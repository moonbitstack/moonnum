Fixed point

A real at a width the caller picks, with the transcendentals a width is for.

pub fn parse_fixed(StringView, Int32) -> Fixed raise Refused

A decimal literal from outside: an optional sign, digits with an optional point, and an optional exponent. Anything else is refused with where it stopped.

pub struct Fixed { mantissa : @bigint.BigInt bits : Int32 }

A real number carried as mantissa / 2^bits.

bits is the number of fractional bits, so the value has about bits * 0.301 decimal digits after the point. An operation keeps the left operand's width and brings the right one to it, so two widths give the answer the left width can hold rather than a wrong one.

A value outside an operation's domain, such as the square root of a negative number, stops the program with the reason, as a division of integers by zero does: these operations are written with + and * and cannot raise. Text from outside goes through parse_fixed, which does.

Implements Add (+) · Compare (<, <=, >, >=) · Div (/) · Eq (== and !=) · Mul (*) · Neg (unary -) · Show (to_string()) · Sub (-) — the methods they promote are public on Fixed.

pub fn Fixed::abs(Self) -> Self

The absolute value.

pub fn Fixed::approx(Self, Self, Self) -> Bool

Whether the two are within tolerance of each other.

pub fn Fixed::at(Self, Int32) -> Self

The same value at another width: exact when it widens, truncated when it narrows.

pub fn Fixed::atan(Self) -> Self

The arctangent, by halving the angle until the series converges and doubling the result back. atan x = 2 atan (x / (1 + sqrt(1 + x^2))) holds for every x, and each halving quarters the argument, so the Taylor series is reached after a handful of steps from anywhere.

pub fn Fixed::bits_for_digits(Int32) -> Int32

pub fn Fixed::cos(Self) -> Self

The cosine, by the same reduction and the Taylor series that starts at one.

pub fn Fixed::div(Self, Self) -> Self

Truncated to the left width. A zero divisor stops the program, as it does for the integers underneath.

pub fn Fixed::exp(Self) -> Self

pub fn Fixed::is_zero(Self) -> Bool

Whether the value is exactly zero.

pub fn Fixed::ln(Self) -> Self

The natural logarithm, by ln(m) + k ln(2) with m in 1..2 and the atanh series for ln(m).

pub fn Fixed::ln2(Int32) -> Self

ln(2) at the given width, 2 atanh(1/3) past the width of the constant.

pub fn Fixed::of_decimal(String, Int32) -> Self

A decimal literal at the given width: "0.5772156649", "-3.14", "1e-40".

This is how a constant that is known to more digits than a double holds gets into a computation without a caller having to hand-count the places. The digits are read as an integer and divided by the matching power of ten once, so the only rounding is that single division. It is for constants a program carries; text from outside goes through parse_fixed.

pub fn Fixed::of_int(Int32, Int32) -> Self

pub fn Fixed::of_scaled(String, Int32, Int32) -> Self

pub fn Fixed::one(Int32) -> Self

pub fn Fixed::pi(Int32) -> Self

Pi at the given width, Machin's formula past the width of the constant.

pub fn Fixed::pow(Self, Self) -> Self

x^y, through exp(y ln x). The base must be positive: a fixed-point value has no branch for a negative base and a fractional exponent.

pub fn Fixed::sin(Self) -> Self

The sine, by range reduction to -pi .. pi and the Taylor series.

Binary floats

A real carried to a width the caller picks: the significand as wide as it needs, an exponent of its own, and a direction for the bits that do not fit.

pub struct BigFloat { kind : Kind mantissa : @bigint.BigInt exponent : Int32 precision : Int32 }

A real number carried to a precision of its own.

The value is mantissa * 2^exponent while it is finite, with the significand an integer of no more bits than precision says. The exponent is binary because the arithmetic underneath is binary: multiplying by ten would round where multiplying by two does not.

Every operation rounds its result to a width — the wider of its operands, or the one a Context names — and keeps that width on the answer, so the next operation inherits it without the caller having to repeat it.

Implements Add (+) · Compare (<, <=, >, >=) · Default (default()) · Div (/) · Eq (== and !=) · Mul (*) · Neg (unary -) · Show (to_string()) · Sub (-) — the methods they promote are public on BigFloat.

pub fn BigFloat::abs(Self) -> Self

The absolute value, at the same width.

pub fn BigFloat::acos(Self, context? : Context) -> Self

The arccosine, as a quarter turn less the arcsine.

pub fn BigFloat::acosh(Self, context? : Context) -> Self

The inverse hyperbolic cosine, as asinh(sqrt(x^2 - 1)), which is real from one upwards and holds its digits there where ln(x + sqrt(x^2 - 1)) would not.

pub fn BigFloat::asin(Self, context? : Context) -> Self

The arcsine, through atan(x / sqrt(1 - x^2)), which is real only inside the unit interval.

pub fn BigFloat::asinh(Self, context? : Context) -> Self

The inverse hyperbolic sine, as ln(1 + u) with u = x + x^2 / (sqrt(1 + x^2) + 1).

The 1 + that would swallow a small argument never gets formed: the rational form of the square root keeps the small part, and ln_one_plus is the logarithm that can take it.

pub fn BigFloat::atan(Self, context? : Context) -> Self

The arctangent, at the context's width and direction.

pub fn BigFloat::atanh(Self, context? : Context) -> Self

The inverse hyperbolic tangent, as half the log of (1 + x) / (1 - x).

At one the answer is unbounded and the two infinities are the answer; past it there is no real value.

pub fn BigFloat::cos(Self, context? : Context) -> Self

The cosine, at the context's width and direction.

pub fn BigFloat::cosh(Self, context? : Context) -> Self

The hyperbolic cosine, at the context's width and direction.

pub fn BigFloat::div(Self, Self) -> Self

The quotient, answering ±inf and nan where the divisor is zero: the operator cannot raise, so it says what the standard says.

pub fn BigFloat::divide(Self, Self, context? : Context) -> Self raise Refused

The quotient, raising ZeroDivision instead of answering an infinity.

The operator cannot raise, so it answers ±inf and nan the way IEEE 754 does; a caller who would rather be told calls this.

pub fn BigFloat::e(context? : Context) -> Self

pub fn BigFloat::exp(Self, context? : Context) -> Self

Reads what float() reads: an optional sign, digits with an optional point and exponent, a single underscore between digits, surrounding whitespace, and inf, infinity and nan in any case. pub fn BigFloat::tan(Self, context? : Context) -> Self

The tangent, as the sine over the cosine.

pub fn BigFloat::tanh(Self, context? : Context) -> Self

The hyperbolic tangent, as the sine over the cosine.

pub fn BigFloat::to_bigint(Self, rounding? : Rounding) -> @bigint.BigInt raise Refused

The value rounded to an integer, Nearest being ties to even.

An infinity and a NaN have no integer, and saying so is the point: a caller handed zero instead would not know it had not been given one.

pub fn BigFloat::to_decimal(Self, Int32) -> String

This is the spelling for a table or a printed constant, so the count is a promise rather than a maximum: to_decimal(2) of one half is 0.50.

pub fn BigFloat::to_double(Self) -> Double

The nearest double, ties to even.

A value above the largest double is an infinity and one below the smallest is a zero, which is what the host does with the same value; inside that range the answer is the correctly rounded double of the exact value.

pub fn BigFloat::to_fixed(Self, Int32) -> Fixed raise Refused

The value as a fixed-point number with bits fractional bits, rounded half to even on the exact value.

The width is the caller's because a Fixed has no precision of its own: the count of fractional bits decides how finely it can sit, and a value far from one needs more of them for the same count of digits.

pub fn BigFloat::to_significant(Self, Int32) -> String

The value with digits significant decimal digits, trailing zeros dropped and the point placed where the plain form keeps it.

pub fn BigFloat::zero(context? : Context) -> Self

The number zero.

pub struct Context { precision : Int32 rounding : Rounding }

A width in bits and the direction a result that does not fit is rounded in.

The two travel together because a rounding mode without a width has nothing to round, and a width without a mode leaves the last bit to chance.

pub fn Context::div(Self, BigFloat, BigFloat) -> BigFloat

The quotient of a and b at this width and rounding, answering ±inf and nan where that is the answer.

pub fn Context::divide(Self, BigFloat, BigFloat) -> BigFloat raise Refused

The quotient of a and b, raising ZeroDivision for a zero divisor.

pub fn Context::new(Int32, rounding? : Rounding) -> Self

A context of precision bits, rounding to nearest even unless told otherwise.

A width below one is raised to one: a significand of no bits holds nothing but zero, and silently answering zero for every operation is worse than answering the one bit that was asked for.

pub(all) enum Kind { Finite PositiveInfinity NegativeInfinity NotANumber }

What a BigFloat is.

A caller who matches on this has seen every value the type can hold, which is the reason it is one enum and not three predicates.

pub(all) enum Rounding { Nearest Floor Ceiling Down Up }

How a result that does not fit the width it is rounded to is rounded.

The five are the reference's n, f, c, d and u. Nearest breaks a tie toward the even digit, so a sequence of roundings does not drift upward the way ties-away-from-zero does.

Implements Show (to_string()) — the method it promotes is public on Rounding.

Numbers

The tower: one value that can be any of the four kinds.

pub fn parse(StringView) -> Number raise Refused

parse(text): read a Python number literal and keep the kind it spelled.

A / makes a fraction, a trailing j or i makes a complex number, a point or an exponent or inf/nan makes a float, and anything else is an integer in whatever base its prefix names.

pub(all) enum Number { Int(@bigint.BigInt) Float(Double) Fraction(Fraction) Complex(Complex) }

A number of any kind, as the tower arranges them.

Promotion goes Int → Fraction → Float → Complex. Comparison is exact across the tower: an integer is never rounded to a float to be compared with one.

Errors

One type, four cases.

pub(all) suberror Refused { Malformed(at~ : Int32, reason~ : String) ZeroDivision Overflow(reason~ : String) Domain(reason~ : String) }

Everything this library refuses, in one type.

Malformed carries the offset where the input stopped making sense, in UTF-16 code units — the unit StringView indexes by — so a caller can point at the character instead of at the string.
